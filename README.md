Instructions to deploy:
1. ZIP file extract করুন এবং সব ফাইল structure অনুযায়ী রাখুন।
2. GitHub repository (my-website) তৈরি করুন।
3. ZIP ফাইলের সব ফাইল Upload করুন।
4. Repository → Settings → Pages → Source → main branch + root folder select করুন।
5. Save করুন এবং কিছুক্ষণ পর Published URL পাবেন।
6. ওয়েবসাইট live।
